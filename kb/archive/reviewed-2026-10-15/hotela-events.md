# Hotela Event Management

## What Hotela Event Management does

Hotela Event Management tracks events held at a hotel or restaurant, such as weddings. It has three tabs: All Events, Expenses and Calendar.

## Hotela events list

- Each event shows event ID, event name, customer name, event type, event date, guest count, revenue and pending balance.
- Event types include Wedding.
- Pending balance shows how much of the event amount is still unpaid.
- Staff can filter events by name or ID, branch, event type, status, month, year and date range.

## Hotela event money

- Event payments appear in Hotela Transactions as Event Payment.
- The Expenses tab tracks the costs of events.
- The Calendar tab shows events by date.

## Not confirmed for events

The fields on the new event form, event packages, menus, venue halls and booking rules are not documented, so those details are not confirmed.
